# Zosha Luxe — وب‌سایت اختصاصی کلینیک زوشا

نسخه دمو/پرزنتیشن حرفه‌ای وردپرس برای «کلینیک زیبایی و پوست زوشا» با طراحی اختصاصی RTL و هویت لوکس سرمه‌ای–شامپاینی. توسعه قالب و افزونه اختصاصی با نام سازنده **حسن مجتهدی - Hassan Mojtahedi** انجام شده است.

## معماری

- **قالب اختصاصی `Zosha Luxe`**: بدون وابستگی به Elementor/Elementor Pro؛ طراحی و کامپوننت‌ها با PHP/CSS/JS اختصاصی برای کنترل کامل روی ظاهر، سرعت و ریسپانسیو بودن.
- **افزونه اختصاصی `Zosha Suite`**: رزرو، ورود OTP، پیامک، پنل کاربری، فاکتور، چت آنلاین، درخواست تماس، تنظیمات برند و اتصال به WooCommerce.
- **وابستگی عمومی**: WooCommerce رایگان از مخزن رسمی وردپرس، فقط برای پرداخت/سفارش و بیعانه رزرو. اگر بیعانه صفر باشد، رزرو بدون WooCommerce هم ثبت می‌شود.

## امکانات پیاده‌سازی‌شده

- صفحه اصلی لوکس با Hero، خدمات، نمونه‌کارها، دانستنی‌ها، رزرو و تماس/نقشه.
- صفحات اختصاصی خدمات، آرشیو خدمات، نمونه‌کار، بلاگ، درباره ما، تماس با ما، رزرو و حساب کاربری.
- مگامنو دسکتاپ، منوی موبایل، نوار پیشرفت اسکرول، موشن‌های ورود، hover و دکمه magnetic؛ با رعایت `prefers-reduced-motion` در CSS.
- ورود مشتری فقط با شماره موبایل و کد OTP در رابط کاربری سایت؛ مدیر وردپرس همچنان از ورود امن استاندارد WordPress برای `wp-admin` استفاده می‌کند تا دسترسی مدیریتی قفل نشود.
- محدودیت درخواست OTP، انقضای ۵ دقیقه‌ای، محدودیت تلاش ناموفق و رمزگذاری هش‌شده کد.
- رزرو آنلاین: خدمت، تاریخ، ساعت، یادداشت، جلوگیری از رزرو هم‌زمان یک slot، وضعیت‌های رزرو و تاریخچه کاربر.
- پرداخت بیعانه اختیاری با WooCommerce و محصول مجازی مخفی.
- پیامک هنگام ثبت نوبت، تأیید پرداخت، تغییر وضعیت و ثبت درخواست تماس.
- پنل‌های پیامکی preset: IPPanel، Kavenegar، Ghasedak و MeliPayamak؛ به‌علاوه **Generic REST Adapter** برای پنل‌های دیگری که REST API دارند.
- پنل تنظیمات برای اطلاعات تماس، اینستاگرام، واتساپ، تلگرام، آدرس، نقشه، تصویر/ویدیوی Hero، رسانه گالری، ساعت کاری، رزرو و پیامک.
- چت آنلاین واقعی داخل سایت: ایجاد گفت‌وگو با token امن، ذخیره پیام‌ها، polling دوره‌ای، پاسخ کارشناس از مدیریت وردپرس؛ در حالت آفلاین تماس/واتساپ/تلگرام و درخواست تماس نمایش داده می‌شود.
- فاکتور/رسید نوبت با دسترسی کنترل‌شده و امکان Print / Save as PDF از مرورگر.
- WooCommerce account endpoint برای «نوبت‌های من».
- CPTهای مستقل برای خدمات، نمونه‌کارها، نوبت‌ها، درخواست تماس و چت‌ها.
- محتوای اولیه خدمات و مقالات به‌صورت قابل‌ویرایش از پنل وردپرس.

## رسانه

در نسخه دمو، URL یک تصویر عمومی از فضای پروژه زوشا در مجتمع تندیس و یک نمای عمومی از محتوای اینستاگرام به‌عنوان reference اولیه قرار داده شده است. فایل ویدیوی اصلی زوشا در این محیط قابل بازیابی مستقیم نبود؛ به همین دلیل هیچ ویدیوی ساختگی داخل بسته قرار داده نشده است. فیلد `hero_video` برای MP4/WebM واقعی آماده است و با وارد کردن URL فایل رسانه‌ای خود کلینیک، Hero خودکار ویدیویی می‌شود.

## نکته درباره «تمام پنل‌های پیامکی ایرانی»

هیچ ادعایی مبنی بر live-test شدن تک‌تک برندهای پیامکی ایران وجود ندارد؛ برای این کار حساب و API credential واقعی هر سرویس لازم است. چهار preset پرکاربرد پیاده‌سازی شده و Generic REST به‌گونه‌ای طراحی شده که سایر پنل‌های REST را بدون تغییر کد، با Endpoint/Header/Body دلخواه متصل کند. سرویس‌های غیر REST یا APIهای بسیار اختصاصی ممکن است به adapter کوچک جداگانه نیاز داشته باشند.
